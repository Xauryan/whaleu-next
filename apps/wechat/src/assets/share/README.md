# Private-safe profile share cover

The original neutral WhaleU cover prevents the native share surface from capturing
private Me-tab content. It contains no avatar, UID, demographic fields, saved
content or user-specific metadata. The native runtime ships only `profile.png`.

Regenerate with the existing workspace Sharp dependency from `profile.svg` at
500 × 400 pixels. Do not replace it with a live Me screenshot or private profile
fields. Source SVG is authoring-only and is not copied by the native build.
